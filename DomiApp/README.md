# DomiApp - Aplicación de Domiciliarios

## Estructura
- `app.py` : Backend Flask completo
- `templates/` : Frontend HTML con Bootstrap + Leaflet
- `requirements.txt` : Dependencias

## Cómo ejecutar (Local)

```bash
cd domiapp
pip install -r requirements.txt
python app.py
```

Abre: http://127.0.0.1:5000

### Cuentas de prueba
- Cliente: cliente@demo.com / 123456
- Domiciliario: domi@demo.com / 123456
